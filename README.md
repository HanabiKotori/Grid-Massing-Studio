# 场馆白膜 · Grid Massing Studio

基于 Vue 3 + Three.js 的场馆白膜（体量模型）在线生成工具。在地面网格上点选顶点画出场地平面，输入净高即可生成可交互的三维白膜体量；随后可在馆内绘制标准 / 脚手架 / 光地三种展台，摆放楼梯、洗手间、出入口、内墙以及座椅、沙发、茶几等家具，并以第一 / 第三人称方块角色漫游检查。

- 一切以 1 米网格为单位，坐标单位为米
- 数据纯前端保存，支持 JSON 导入 / 导出，便于与外部系统对接
- 默认使用浏览器本地 GPU 渲染，支持移动端与自动降级画质

## 功能概览

### 建模

| 对象 | 能力 |
| --- | --- |
| 场馆 | 多边形轮廓绘制、净高 2–24 m、封顶开关、半透明（X-Ray）查看、重新绘制；银灰金属墙面 + 共享 1K 法线贴图 |
| 标准展台 | 下部带 2 m 入口的围挡 + 闭合顶板，顶板可去除（立柱一并隐藏）；高度 1–8 m，面积 ≥ 3 m² |
| 脚手架展台 | 底部为 0.15 m 微凸台板，上部架空；按面积自动布置边界 / 内部立柱与顶部双向桁架，顶棚可开关；立柱 / 横梁使用独立拉丝金属法线；高度 1–8 m |
| 光地展台 | 仅 0.15 m 微凸台板，无围挡与顶盖，闭合轮廓后直接生成 |
| 展台通用 | 包围盒长宽调整、拖动移动、Alt + 拖动或右键单击旋转（90°）、重命名、Logo 上传（标准展台四边左下角；脚手架 / 光地正面落地牌）、红 / 黄 / 灰标记 |
| 基础设施 | 楼梯、洗手间、电梯间（1–6 部电梯门）、出入口、内墙；可拖动、右键旋转 90°、逐项调整尺寸与数量 |
| 家具 | 圆座椅、扶手椅、沙发、圆茶几、方茶几；仅能完整摆在展台内部，尺寸可按类型调整；共享 1K 灰织 / 石墨 / 灰缎金属贴图 |
| 合并 | 相邻展台可合并为一组，共享描边配色；可选统一高度或保留各自高度 |

### 场景与展示

- **分组工具栏**：视角（俯视 / 轴测 / 适配，快捷键 `T` / `I` / `F`）、显示（名称 / 刻度 / 面积 / 网格）、画质（极致 / 高 / 中 / 低）、数据（汇报图 / 导入 / 导出）二级菜单在工具栏内部展开；执行菜单操作后保持展开，便于连续调整，再次点击一级按钮或按 `Esc` 收起；打开天气 / 帮助 / 展示模式或进入漫游时自动关闭菜单。PC 竖向、移动端横向，移动端支持按内容宽度收起 / 展开。带指北罗盘、1 m 网格、尺寸刻度、展台名称与面积标注
- **自动保存与恢复**：场馆名称、场馆、展台、设施、天气和太阳时间写入 IndexedDB，刷新或重新打开页面自动恢复；手动导入 JSON 时导入数据优先并覆盖自动保存
- **场馆名称**：点击左上角品牌标题可直接重命名，名称会进入场景 JSON、自动保存和汇报图
- **展示模式**：按 `S` 或从视角菜单进入，隐藏全部 UI 并缓慢环绕场馆；展台名称分布到馆外并用折线连接展台，基础设施名称隐藏，按 `Esc` 或右下角按钮退出
- **动态太阳**：可拖动的 24 小时时间轴，按真实时间流速推进并默认当前本地时间；支持播放 / 暂停与一键回到当前时间（约 0.9s 光照平滑过渡）。常规画质夜间使用自发光灯泡 + 烘焙地面光池，极致画质改用只向下发光的实时聚光灯
- **天气**：工具栏「天气」或 `Alt+W` 打开面板，`Alt+W` 只负责打开 / 关闭面板，不改变当前天气。切换天气时天空、雾和主光会用约 0.9 秒平滑过渡。面板顶部有天气效果总开关，关闭时默认为晴天；选择任意天气或应用实时天气后自动开启。顶部通过高德天气 API 查询实时天气，默认城市贵阳，也可输入城市名 / adcode；PC 端场馆首次生成或载入后会按上次查询城市自动应用实时天气，并在时间组件右侧显示当前天气；移动端默认不自动应用实时天气，可在面板中打开「使用实时天气」开关；启用后查询新城市会自动同步，关闭开关回到晴天。下方可分别拖动雨、雪、沙尘的粒子浓度（0–100%）和能见度，拖动时弹窗与遮罩暂时隐藏、只保留当前滑块方便预览，松开后恢复；拖动即时更新。当前天气没有对应粒子时提供状态提示和同类天气预览。桌面端为左右双栏，天气预设区域更大；移动端自动改为单栏，并可手动切换 13 种天气。天气联动天空、雾、太阳 / 补光强度、雨雪 / 沙尘粒子和雷暴闪光。少云、多云和阴天使用程序化云影层，云影会随风缓慢扫过地面，太阳主光同步轻微明暗变化；只在白天明显，不做真实云体遮挡。第一人称漫游时额外叠加纯 CSS 镜头氛围层（边缘水痕、雾气、沙尘污渍、雷暴闪白），不增加 WebGL pass；天气只影响室外粒子，封闭顶棚内不会出现降水
- **汇报图**：数据菜单「汇报图」生成约 2400 × 1500 的高质量俯视 PNG，包含场馆名称、面积、覆盖率、展台名称与编号；显示菜单中已打开的面积和刻度会一并导出，刻度使用 `L / W / H` 长宽高代号，并对重叠数字自动避让；导出时临时切换为清晰日光和图纸描边，不影响当前场景
- **方块角色漫游**：需要先生成场馆；进入选点时视角会先切到俯视并适配场馆大小。第一人称低头可见方块身体和绿色准星，第三人称显示完整角色；`P` 或工具栏进入漫游，`V` 或移动端按钮切换视角，带约 0.32s 平滑机位过渡；`R` 约 0.7s 返回起点；按住 `Alt` 临时释放鼠标；`F1` 打开帮助。WASD 移动、Shift 加速、空格跳跃、Esc 退出；第三人称镜头带墙体 / 展台遮挡收缩；靠近出入口可左键开合；移动端提供虚拟摇杆、回到起点、跳跃按钮、工具栏折叠与横屏引导，漫游时罗盘位于时间组件左侧
- **漫游缩略地图**：PC 右下角、移动端时间组件下方显示场馆轮廓、展台、当前位置与朝向；漫游时自动隐藏编辑侧栏
- **编辑 / 预览模式**：预览模式（`render=1`）隐藏编辑面板、导入按钮与全部编辑快捷键，仅保留视图、导出与漫游，适合嵌入到其他系统做纯展示
- **画质分级**：极致 / 高 / 中 / 低四档；极致模式使用向下 180° 的实时场馆聚光灯、4096 阴影贴图与更高像素比，不使用烘焙光池；其余档位按 GPU 型号预判并在运行中根据帧率自动降级
- **应用内帮助**：工具栏 / 欢迎页「帮助」按钮或 `F1` 打开帮助；PC 使用分栏面板，并在顶部提供适配视图、网格、名称、面积、天气面板、进入漫游等快速设置，点击后自动关闭帮助并执行；移动端使用独立的全屏手风琴指南，内容按触屏、横屏和摇杆操作单独编写
- **欢迎页与结构面板**：未创建场景时欢迎页水平居中，右侧场景结构隐藏；生成场馆后结构面板在 PC 端从右向左滑入，面积 / 覆盖率固定在顶部
- **示例场景**：一键载入 130 × 70 m 的 W1 展馆示例（19 个展台 + 41 个设施，W1C01 为脚手架，咖啡洽谈区为光地并含 7 件家具）

### 编辑体验

- 撤销 / 重做（最多 60 步，连续操作 260 ms 内合并为一次）
- 展台 / 设施重叠校验、展台是否完全位于馆内的校验、轮廓自相交校验
- 家具需完整落在展台轮廓内；展台移动、旋转、缩放时家具会跟随，删除展台时自动清理其内部家具
- 选择家具进行摆放时，标准展台顶板与脚手架顶棚自动变为半透明，便于观察展台内部
- 展台与设施选中、面板定位、批量删除；选中展台 / 设施时自动展开对应卡片，等展开动画完成后再一次性滚动到条目，避免跳动
- 按住空格进入纯视角浏览模式，右侧状态显示「浏览模式」，松开恢复「编辑模式」；画布同时给出浏览提示
- 右侧「场馆 / 展台 / 基础设施」卡片支持展开收起，带高度与透明度过渡；面积 / 覆盖率固定顶部，不随内容收缩
- 导入时对数据做容错与范围收敛，兼容旧字段

## 技术栈

- **Vue 3**（`<script setup>` + TypeScript，无状态管理库）
- **Three.js**：`WebGLRenderer`、`ExtrudeGeometry`、`OrbitControls`、`CSS2DRenderer`、`InstancedMesh`
- **polygon-clipping**：多边形求交 / 并集，用于重叠判定、合并轮廓与组选
- **Vite 7**：开发服务器与构建，`base: './'` 可直接部署到任意子路径

## 快速开始

环境要求：Node.js `^20.19.0` 或 `>=22.12.0`（Vite 7 要求）。

```bash
# 安装依赖（任选其一）
pnpm install
# npm install

# 启动开发服务器（默认 http://localhost:5173）
pnpm dev

# 类型检查 + 生产构建，输出到 dist/
pnpm build

# 本地预览构建产物
pnpm preview
```

### 高德实时天气

在项目根目录 `.env.local` 中配置高德开放平台 Web 服务 Key：

```bash
VITE_AMAP_KEY=your_amap_web_service_key
```

可以复制 `.env.example` 作为模板。天气面板默认查询贵阳，支持输入城市名或 adcode；实时天气会映射到最接近的场景预设，手动天气仍然可用。

> 前端直连会把 Key 暴露在构建产物中，仅适合内部演示；正式部署建议通过服务端代理转发高德请求并限制 Key 的域名 / IP。

> 若 Windows 下 pnpm 报 `untrusted mount point` 或读取 `esbuild/package.json` 失败，这是卷不允许遍历 junction 导致的。项目已在 `pnpm-workspace.yaml` 中配置 `nodeLinker: hoisted` 与 `packageImportMethod: copy`，重新执行 `pnpm install` 即可改用无 junction 的平铺依赖布局。

## 使用流程

1. 点击「开始绘制」（或面板中的「绘制场地面积」），在网格交点上依次单击放置顶点
2. 点击起点、双击或按 Enter 闭合轮廓，在底部面板输入净高并生成场馆白膜
3. 在展台卡片选择「+ 标准 / + 脚手架 / + 光地」，在场馆内画出展台轮廓；前两者设定高度，光地直接生成微凸平台
4. 按需添加基础设施：出入口会自动吸附到最近的墙体或内墙上，并在墙上开洞
5. 添加家具：先在面板中点击「+ 圆座椅 / 扶手椅 / 沙发 / 圆茶几 / 方茶几」，再点击展台内部落位
6. 切换到「预览」或「漫游」检查结果，最后通过工具栏「导出」保存场景 JSON

> 绘制展台时场馆会自动半透明；场馆内部区域已扣除 0.4 m 墙厚与安全距离，展台必须完全落在该范围内。

### 分层说明

- `App.vue` 是唯一的数据源，持有 `venue`、`booths`、`infras` 与编辑状态；所有合法性校验、撤销快照、导入导出都在此完成
- `Stage.ts` 不持有业务数据副本，通过 `setVenue / setBooths / setInfras / setScene` 接收数据重建图层，通过 `StageOptions` 回调把鼠标与漫游事件交回 Vue
- `build.ts` 只负责几何与材质，输入米制坐标，输出 `THREE.Group`
- `polygon.ts` 是纯函数库，便于单独测试或复用

## 场景 JSON 格式

导出文件形如 `grid-massing-YYYY-MM-DD-HH-mm-ss.json`：

```json
{
  "version": 1,
  "venueName": "W1 展馆",
  "weather": "cloudy",
  "weatherOn": true,
  "sunProgress": 0.5,
  "venue": {
    "points": [
      { "x": -65, "z": -35 },
      { "x": 65, "z": -35 },
      { "x": 65, "z": 35 },
      { "x": -65, "z": 35 }
    ],
    "height": 7,
    "ceiling": false
  },
  "booths": [
    {
      "id": "b1",
      "name": "展台 01",
      "points": [{ "x": 0, "z": 0 }, { "x": 6, "z": 0 }, { "x": 6, "z": 4 }],
      "height": 3,
      "kind": "scaffold",
      "canopy": true,
      "groupId": "g1",
      "mark": "red",
      "logo": "<PNG base64，不含 data URL 前缀>",
      "data": { "externalId": "A-01" }
    }
  ],
  "infras": [
    {
      "id": "inf1",
      "kind": "gate",
      "name": "出入口 01",
      "x": -37,
      "z": 35,
      "rotation": 0,
      "width": 5,
      "depth": 0.5,
      "height": 4,
      "open": false
    }
  ]
}
```

字段说明：

- `Pt`：`{ x, z }`，`x` 为东西向、`z` 为南北向，单位米
- `venue.ceiling`：是否封顶，默认 `false`（敞开便于查看内部）
- `booths[].kind`：`massing`（默认）/ `scaffold` / `openfloor`
- `booths[].canopy`：仅脚手架展台有效，是否带顶棚，默认 `true`
- `booths[].noTop`：仅标准展台有效，`true` 表示去掉顶板与立柱、只保留围挡
- `booths[].mark`：`red` / `yellow` / `gray`；旧数据中的 `marked: true` 会按红色兼容
- `booths[].data`：任意业务字段，导入导出原样保留
- `infras[].kind`：`stairs` / `restroom` / `gate` / `elevator` / `wall` / `chair` / `armchair` / `sofa` / `table-round` / `table-square`
- `infras[].count`：仅电梯间有效，范围 1–6
- `infras[].open`：仅出入口有效，控制门扇开合
- 家具高度由类型固定；圆座椅固定 0.6 × 0.6 × 0.5 m，扶手椅固定 1 × 1 × 1.0 m（座高 0.5 m）；沙发高 1.2 m、方茶几高 0.5 m、圆茶几高 1 m，长宽可调
- 导入时会裁剪到合法范围（例如标准展台高度 0.4–8 m、场馆净高 2–24 m、光地高度固定 0.15 m），自动修正重复 id，并丢弃不在展台内部的家具

## 对外 JavaScript API

页面加载后可通过 `window.gridMassing` 与宿主系统对接：

```js
// 导出展台数组（深拷贝，logo 为纯 base64）
const booths = window.gridMassing.exportBooths()

// 导出完整场景（与「导出」按钮内容一致）
const scene = window.gridMassing.exportScene()

// 导入场景：支持 JSON 字符串或对象；返回是否成功
window.gridMassing.importScene(jsonText)

// 切换纯渲染（只读）模式
window.gridMassing.setRenderMode(true)
```

开发模式下还会在 `window.__stage`（Stage 实例）与 `window.__app`（响应式状态）上挂调试引用。

### URL 参数

| 参数 | 说明 |
| --- | --- |
| `?render=1` | 纯渲染 / 只读模式，隐藏编辑面板与导入按钮，禁用全部编辑快捷键 |
| `?mobile=1` | 强制按移动端交互（虚拟摇杆、竖屏提示） |
| `?quality=ultra\|high\|medium\|low` | 指定画质，同时关闭自动降级；`ultra` 为实时灯光极致模式 |

## 实现要点

- **墙体生成**：场馆轮廓先内缩墙厚（0.24 m）形成带孔洞的 `Shape` 再挤出；若存在出入口，则按墙段切分为墙垛 + 过梁 + 转角柱，保证开洞后仍然闭合
- **展台构造**：标准展台为四周带 2 m 居中缺口的围挡 + 闭合顶板；脚手架展台为 0.15 m 台板 + 加粗立柱（0.18–0.28 m）+ 顶部横梁（0.12–0.2 m）+ 可选顶板，台板以上架空。脚手架按面积估算柱距（约 4–10 m，目标约 10 个柱跨），自动在轮廓边界和内部布置立柱；内部网格线直接取边界柱坐标，保证立柱与顶部双向桁架对齐，光地展台同样为 0.15 m 台板。合并组只有全部为标准展台且高度一致时才会合并轮廓，其余按组着色、各自保留形态
- **Logo 定位**：标准展台沿轮廓每条边各贴一个 Logo，均位于该边外观视角的左下角；脚手架 / 光地仍为正面落地立牌，立牌落在 0.15 m 台面上
- **场馆材质**：银灰金属墙面使用 `public/textures/venue` 下的共享 1K 法线贴图与低饱和浅灰地面，只调整表面光照质感，不改变墙体 / 门洞结构；来源与许可见同目录 `sources.json`
- **展台材质**：标准 / 光地使用 `public/textures/booths/metal-normal.jpg` 的板缝法线；脚手架台板与顶棚继续用板缝法线，立柱 / 横梁单独使用 `brushed-normal.jpg` 拉丝金属法线，避免细金属件上出现板缝和铆钉。围挡、立柱和横梁的 BoxGeometry UV 按米制尺寸缩放，防止长条构件上的法线贴图被拉伸。来源与许可见同目录 `sources.json`
- **家具材质**：使用 `public/textures/furniture` 下的 1K CC0 颜色贴图，软包为浅冷灰细织物、椅背 / 桌面为石墨斜纹、框架 / 桌腿为低金属度灰缎金属；贴图按资源只加载一次，所有家具共享，ghost 预览不贴图。来源与许可见同目录 `sources.json`
- **重叠判定**：展台之间使用 `polygon-clipping` 的相交面积（> 0.02 m² 视为重叠，允许贴边拼接）；设施与家具之间使用分离轴定理（OBB）；家具额外校验整体轮廓是否落在同一展台内
- **性能**：常规画质场馆夜间照明使用一个 `InstancedMesh` 灯泡 + 烘焙好的 Canvas 光池贴图；极致画质改为最多 24 盏向下 180° 的实时 `SpotLight`，不生成光池。少云 / 多云的程序化云影使用一张 256px 可平铺纹理和一个透明地面层，不增加后处理 pass。`three` 单独分包；变更时只重建对应图层（`setVenue` / `setBooths` / `setInfras`）
- **P0 性能节流**：阴影贴图改为约 12.5 Hz 手动刷新；CSS2D 标签约 30 fps，罗盘约 20 fps；复用 `updateSun` 临时颜色，并在无粒子 / 无云影时跳过更新。保持画质档位、像素比、阴影分辨率和粒子数量不变
- **画质降级**：先按 GPU 名称预判，运行中每 90 帧统计平均帧时长，超过 26 ms 依次降为「中」「低」；低画质关闭实时阴影并降低像素比与灯位密度。极致档需手动选择，不参与自动降级
