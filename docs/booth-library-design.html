01 / CATALOG
模型库

八个可认出来的展台，
不是八个硬编码分支。

每个模型保留现有 BIM 式白膜基因：可绘制任意多边形轮廓、可设高度、Logo、展商和标记。差异来自墙板开合、框架、顶棚、门楣和台地，而不是另写一套编辑器。

02 / LANGUAGE
模型语言

先拆构件，
再组合成模型。

模型卡片只是预设。底层统一拆成六个构件参数，任意模型都可以改其中一两个，而不是复制整个 builder。

01 / WALL

墙板开合

四面、三面、两面或单面围合；按轮廓边索引记录开口，保留任意多边形。

02 / TOP

顶棚形式

封闭顶板、开放、脚手架顶棚、桁架网格、半透明膜结构。

03 / FRAME

框架系统

白膜柱、八棱柱、金属脚手架、门头钢架；决定细柱和横梁。

04 / FASCIA

门楣

0 / 0.3 / 0.6 / 0.9 m 高度，正面或整圈，承载 Logo 和展商名。

05 / PLATFORM

台地

0 / 0.15 / 0.3 / 0.45 m，可加单侧或双侧台阶。

06 / OPEN EDGE

开合边

按 points 的边序号记录；默认模型给推荐开边，用户可点击某条边切换。

05 / FLOW
交互流程

选模型 → 画轮廓 → 调构件。

模型库不是一步到位的“死模型”。放置后仍然可以改开合边、门楣、台地、高度和顶棚，像现在编辑白膜一样。

01选择模型从右侧模型库选择标准 / 半岛 / 岛型 / 门头 / 桁架。
02绘制轮廓沿用现有矩形拖拽和顶点绘制，模型自动套用推荐参数。
03微调构件点击边切换开合，调门楣高度、台地、顶棚和框架。
04复用与阵列复制、换模型、批量应用；仍然只重建变化的展台。
06 / ROLLOUT
实施建议

先做六个，
双层最后。

标准、标摊、半岛、岛型、门头、光地先形成可用模型库；桁架作为第七个；双层涉及结构、消防和剖面表达，单独设计。

PHASE 01
Recipe + 兼容层style / openEdges / topStyle / fascia / platform；旧 kind 映射。1–2 d
PHASE 02
四个基础模型标准、标摊、半岛、岛型；构件化 buildBooth。3–4 d
PHASE 03
门头 / 光地 / 桁架门楣、台地、桁架网格和灯位点。2–3 d
PHASE 04
模型库 UI缩略图、切换、开合边编辑、单台增量重建。2–3 d
DOUBLE DECK · LATER

双层展台需要楼板厚度、栏杆、楼梯、上下层承载、消防疏散和剖面标注，不应和单层模型塞进同一批实现。建议先用「门头 + 台地」覆盖大部分主展位需求。

07 / DECISIONS
需要拍板

三个方向，
确认后开始落代码。

设计图只做模型库与构件语言，不改当前颜色、评论、存档和分享链路。

Q.01 / SCOPE
首批做哪些？

推荐 标准、标摊、半岛、岛型、门头、光地六种；桁架第二批，双层后续单独立项。

Q.02 / OPEN EDGE
开合边怎么记录？

推荐按轮廓 points 的边序号存 `openEdges`，矩形默认前边；旋转 / 镜像后仍跟随轮廓，不依赖东南西北。

Q.03 / DOUBLE
双层现在做吗？

推荐 先不做。双层会引入楼板、楼梯、栏杆、消防和剖面表达，先把单层六模型做稳。

Q.04 / COLOR
模型切换是否保留颜色？

保留现有标记 / 组色；自定义颜色不在本轮设计范围，后续按独立颜色系统接入，不影响模型配方。
