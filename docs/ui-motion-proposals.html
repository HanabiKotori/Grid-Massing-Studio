界面过渡方案

把项目里所有「硬切」和「跳变」的交互点收进一套统一的动效规范：全部使用非线性缓动， 同一类切换走同一组参数，有前后关系的动作按 40 ms 错峰衔接。下面每一条都可以点击体验。

10 个场景 4 档时长 · 3 条曲线 可慢放观察
00

缓动与时长

全局 token

时长只保留四档，曲线只保留三条。所有过渡必须从这三个变量里取，不再出现 0.15s ease、0.26s 之类散落各处的数值。

--ease-emphasized cubic-bezier(.16, 1, .3, 1) · 进入
--ease-standard cubic-bezier(.4, 0, .2, 1) · 通用 / 退出
--ease-spring cubic-bezier(.34, 1.32, .64, 1) · 小元素
--t-micro110 ms · hover / 按下
--t-small160 ms · 选中 / 淡出
--t-med220 ms · 菜单 / toast
--t-large300 ms · 弹窗 / 抽屉
--stagger40 ms · 承接错峰
为什么不用默认的 ease：浏览器 ease 在 200 ms 内几乎是一条直线，观感「软而糊」。 进入用 emphasized（起步快、尾巴长）显得干脆，退出统一用 standard（对称）， 小元素（圆点、勾选）用 spring 轻轻回弹一点，避免机械感。
01

弹窗

导出 / 确认 / 天气 / 帮助

遮罩和卡片分两拍：遮罩先 160 ms 淡入到位，卡片延迟 40 ms 用 220 ms 抬起。 关闭时反过来——卡片先退，遮罩后走，视觉上不会出现「卡片还在飞、背景已经没了」的割裂。

演示点击按钮，可开慢放观察两拍的关系

删除展台 W1E01

展台内的家具和落地设施会一起移除，且不可撤销。

遮罩opacity · 160ms standard
卡片进入opacity + translateY(10→0) + scale(.96→1) · 220ms emphasized · delay 40ms
卡片退出160ms standard · 无延迟
02

下拉菜单

顶栏四组菜单

从触发按钮的底边生长出来：transform-origin: top，纵向压扁 0.96 再展开， 同时上移 6 px 归位。进入 160 ms，退出 100 ms——收得比开得快，符合「点击后立刻消失」的预期。

演示点击「显示」开合菜单
进入opacity + translateY(-6→0) + scaleY(.96→1) · 160ms emphasized
退出100ms standard · 不做延迟
菜单项悬停background · 110ms standard
03

侧栏收起

预览 / 展示 / 漫游

这是唯一一个「不能补间」的地方：列宽逐帧变化会让 canvas 每帧 resize，出现黑屏闪烁。 所以顺序是——两侧栏内容 160 ms 淡出并轻微内收，等淡出结束（延迟 160 ms）再一次切换列宽。 退出时列宽立即恢复，内容用 180 ms 淡入，保持「先有空间、再有内容」的顺序。

演示点击切换编辑 / 预览
VIEWPORT
侧栏内容opacity 1→0 + translateX(±6px) · 160ms standard
列宽不补间 · 延迟 160ms 后一次性切换
退出列宽立即恢复 · 内容 180ms 淡入

属性面板切换

选中不同对象

现在选中不同对象时整块内容直接换掉，容易「闪」。改成旧内容 120 ms 上移淡出、新内容 180 ms 从下方淡入， 总时长 220 ms，读起来是「换了一张卡片」而不是「刷新了页面」。

选中与悬停

树 / 预设 / 导航

选中态目前三处（结构树、天气预设、帮助目录）已经统一为「紫色文字 + 行尾圆点」， 但圆点是瞬间出现的。改成文字 140 ms 过渡、圆点 180 ms 从 0.2 缩放回弹到位，更轻。

06

Toast

全局提示

从顶栏下方 8 px 处滑入并淡入，220 ms；消失 160 ms 且不做位移，避免「飞走」的干扰。 连续触发时新的叠在下方，旧的保持不动。

实施清单

确认后再动手

现在的 49 处 transition 散落在 styles.css / workbench.css / 各组件里，时长与曲线各不相同。 计划统一到下面这张表，改动集中在 token 层 + 每处加一层包裹，不动业务逻辑。

统一原则：同一类切换只允许一种时长组合。
弹窗 = 160 / 220（延迟 40）；菜单 = 160 / 100；内容切换 = 120 / 180； 选中 = 140 / 160 / 180；布局 = 160 / 立即 / 180；颜色 = 420。
除此之外不再新增时长，需要更慢就开慢放开关看时序，而不是改数值。
