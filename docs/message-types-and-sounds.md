# 消息类型与音效候选

日期：2026-11-22  
音效状态：**已按方案 A 接入**。编辑器 B 类使用 S9，作者或其他访客直接回复、作者解决 / 取消解决使用 S7，作者删除评论使用 S8；A/C/D/E/F 静音。

## 1. 已接入的 Toast 类型

当前统一 ToastHost 支持 A–D 四类；E/F 不进入 Toast 队列。

| 类型 | 名称 | 使用位置 | 默认时长 | 呈现 |
| --- | --- | --- | --- | --- |
| **A** | 操作反馈 | 编辑器保存 / 导入 / 导出 / 复制；分享页复制、发送、删除、登录；多人加入 / 退出 / 全屏提示 | **2.8s** | 底部居中；进度条；可关闭；无操作按钮 |
| **B** | 协作消息 | 编辑器评审新评论；分享页其他访客评论 / 回复 / 作者回复 | **4.2s** | 右上角（桌面）/ 顶部全宽（移动）；可「查看」；进入协作入口 |
| **C** | 系统状态 | 预留给同步 / 连接类 Toast | **3.6s** | 顶部居中；通常仍以状态栏为主 |
| **D** | 阻断错误 | 预留给链接撤销 / 服务不可用类 Toast | **6.0s** | 顶部居中；红色强调；不会自动进入未读 |
| **E** | 表单校验 | 登录、发布、重命名、验证码 | 常驻 | 字段内联，不进入 Toast，故意不自动消失 |
| **F** | 房间消息 | 多人聊天 / 系统提示 | 8s（现有实现） | 聊天流；不进入 Toast |

### 统一行为

- 所有 A–D Toast 都带 **底部进度条倒计时**，进度与 `duration` 同步。
- 进入动画 220ms，离开动画 160ms；列表位移有 `move` 过渡。
- 每个 host 最多同时显示 3 条，超出排队。
- 点击「查看」/关闭会立即结束倒计时并执行动作。
- 相同 `dedupeKey` 的消息会替换旧消息。
- 自己的评论/操作不进入 B 类通知；B 类只通知别人。
- 分享页面板打开时不弹 B Toast，只插入卡片 + 未读；面板关闭或页面隐藏时才弹。
- 无障碍：host 使用 `aria-live="polite"`；D 类卡片使用 `role="alert"`。

> E/F 没有套用进度条，是刻意区分：表单错误不应自动消失，聊天已有自己的 8 秒节奏。若你希望 F 也显示倒计时，可以单独加在聊天条目上。

## 2. 音效候选

你的偏好是 **S2 玻璃双音 / S7 三音风铃** 这一类“玻璃 + 风铃”的清晰、悦耳、短提示。下面按这个方向列备选，全部可在 `docs/notification-sound-options.html` 试听。

### B 类协作消息（唯一建议配音的类型）

| 编号 | 音色 | 适合事件 | 感觉 | 建议 |
| --- | --- | --- | --- | --- |
| **S2** | 玻璃双音 | 普通新评论（当前分享页策略下静音） | 直接、清楚、像“收到” | **保留候选** |
| **S7** | 三音风铃 | 作者或其他访客回复当前访客；作者解决 / 取消解决 | 更完整、友好、存在感更强 | **已接入回复与解决操作** |
| **S8** | 轻鼓双击 | 作者删除当前访客的评论 | 低频、明确、有打断感 | **危险操作专用** |
| **S9** | 纯五度玻璃 | 编辑器新评论 | 比 S2 低、暖、不刺耳 | **已接入编辑器** |
| **S10** | 风铃下行 | 分享页新评论 | 收束、平静、不催促 | 想更安静时 |
| **S11** | 木质双音 | 新评论 / 成功反馈 | 温暖、介于 S1 和 S2 之间 | 觉得玻璃太亮时 |
| **S12** | 水晶单音 | 极简编辑器 / 仅提示“有动静” | 精致、信息量最低 | 最克制 |

### 其他类型

| 类型 | 推荐音效 | 备选 | 说明 |
| --- | --- | --- | --- |
| A 操作反馈 | **无** | S11 / S12 | 编辑器有约 170 个操作 Toast，配音会非常吵；成功反馈靠进度条和文字即可 |
| C 系统状态 | **无** | S10 | 重连/保存状态应保持安静，避免和协作声音混淆 |
| D 阻断错误 | **无** | 无 | 阻断错误本来就该被看到；声音容易惊扰，不建议默认 |
| E 表单校验 | **无** | 无 | 字段内联足够，配音会增加失败感 |
| F 房间消息 | **无** | S12 | 聊天量大；如只对 @ / 提及配音，可用 S12 |

## 3. 推荐组合

### 方案 A：按事件区分（当前实现）

- 编辑器 B：**S9 纯五度玻璃**
- 分享页普通 B：**静音**
- 作者或其他访客直接回复当前访客：**S7 三音风铃**
- 作者解决 / 取消解决你的评论：**B 类通知 + S7**（success / info）
- 作者删除你的评论：**B 类通知 + S8 轻鼓双击**（error / danger）
- A / C / D / E / F：静音
- 只有“与当前访客有关”的操作才在分享页通知并发声；其他用户之间的对话静音
- 评论面板打开时也播放；普通评论只更新卡片，直接回复与作者操作仍弹 B 类通知
- 同类消息 2.5 秒内合并；普通评论刚响过后的直接回复优先发声，不会被合并掉

这是最贴合你偏好的方案：S7 负责“有人回复你 / 作者处理了你的评论”，S8 负责“评论被删除”，编辑器和分享页各有自己的温度。

### 方案 B：一个声音统一（最稳）

- 所有 B 类：**S2 玻璃双音**
- 其他类型：静音
- 不想让用户学习两套声音时使用

### 方案 C：极简

- 所有 B 类：**S12 水晶单音**
- 其他类型：静音
- 最安静，但“作者回复”和普通评论没有区分

## 4. 接入位置

音效接在 B 类事件层，不依赖 Toast 是否显示：

- 编辑器收到访客新评论时播放 S9；评论面板打开时也播放，但只更新列表。
- 分享页在直接回复当前访客、作者解决 / 取消解决时播放 S7；作者删除时播放 S8。
- 普通评论、作者回复其他用户、其他访客之间的操作都不发声。
- 直接回复与作者操作在评论面板打开时也发声并弹 B 类通知；普通评论面板关闭时只弹通知，不发声。
- 编辑器访客新增评论 / 回复仍播放 S9。
- A/C/D/E/F 不调用。
- 浏览器首次用户手势（点击 / 按键）后解锁 AudioContext；未解锁时保持静音。
- 同类消息 2.5 秒内合并为一次声音；直接回复（S7）优先级高于普通评论（S2/S9）。
- 当前未加独立静音按钮，使用系统音量；后续可在顶栏补持久化开关。
