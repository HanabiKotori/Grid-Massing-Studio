规则

网格4 px 基准；面板内边距 8 / 10 / 12；分区之间 16。
圆角控件 4–5，浮层 8，面板直角贴边。不使用 12 以上的圆角。
边框默认 white/7%，聚焦或激活 white/12%。不用外阴影做层级。
强调蓝紫只用于控件与选中行；视口内选中用暖橙，避免与 UI 混淆。
数字面积 / 尺寸 / 坐标全部等宽 + tabular-nums，右对齐。
动效140 ms cubic-bezier(.16,1,.3,1)，只动 opacity 与 transform。
图标24 网格线性，1.5 描边，15–16 px 使用，统一 currentColor。
密度列表行 27 px，工具按钮 26 px，面板标题 34 px。

建议落地顺序

三套桌面方案都能复用现有组件，差异只在壳层与面板拆分方式。我的建议是 C 的骨架 + B 的 ⌘K：场馆这类层级多的场景，结构树和属性分开更耐用；菜单项则收进命令面板，顶栏可以更薄。 移动端选 M2，把"这是什么、多大、有哪些展台"一次讲完。

  1. 抽 token　styles.css 的变量换成深色语义变量（surface / line / ink / accent / select），结构不动，先把底色换掉。
  2. 换壳　顶栏、状态栏、检查器改为固定栏；现有 Inspector 内容原样搬进 C 的左右两栏，拆成"树"和"属性"。
  3. 收窄移动端　isMobile 分支只保留导入、视图、显示、天气、导出；删除绘制与拖拽入口，快捷键分发加只读判断。
  4. 新增只读页　M2 复用 Inspector 的数据源，但不引入任何编辑 action，独立成一个组件。
  5. 可选　命令面板（⌘K）与面板钉住 / 收起，放到第二轮。
