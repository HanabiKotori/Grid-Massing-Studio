S-A 分享页 · 常驻评论栏 主办方与展商逐条评审、需要对照模型 画布少约 350 px，窄屏需可收起 默认采用

E-B 编辑器 · 属性 / 评审 Tab 日常编辑 + 集中处理评论并存 多一层切换，需要未读徽标 推荐采用
E-C 编辑器 · 评审模式 评审会、批量处理、投屏 两套工具栏状态，模式切换成本 二期增强
推荐组合

分享页 S-A ＋ 编辑器 E-B

分享页给固定评论栏，符合评审习惯；编辑器用 Tab 把评论与属性分开，避免属性栏继续变长。S-B 的悬浮样式可以作为 S-A “收起评论”后的状态，不需要单独实现一套页面。

画布与评论同屏 属性栏不变长 复用同一套引脚与卡片
落地顺序
  1. 01projectKey / sceneSignature / 场景解析抽取
  2. 02dataService：share_links + share_comments + 聚合接口
  3. 03分享页 S-A：只读 Stage + 评论栏 + 发布弹窗
  4. 04编辑器 E-B：Tab + 引脚 + 未读 + 定位
  5. 05移动端抽屉 + 链接管理 + 异常状态
回复：S-A + E-B 或：S-A + E-A（先做最轻的一版） 或：S-B + E-C
