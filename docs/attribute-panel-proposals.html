横向是三种组织方式，纵向是四类对象。每格都是 320 px 的实物面板，与真实右栏同宽。 基础设施可以在下方切换子类型，看门窗、电梯、内墙这些特殊字段怎么落进同一套结构。

基础设施

建议：A 的骨架 + C 的数值对齐

A 的留白和分节线最接近 Linear，也不会像 B 那样「框里套框」；把 A 的数值行统一改成 右对齐 + 等宽数字（C 的做法），批量比对尺寸时更顺眼。带选项的字段（类型、开启方式） 用 A 的下划线分段；数量、离地用 C 的步进器和单位后缀；材质色块三套保持一致。

回复 A / B / C 或者：A，但类型切换用 C 的方框
