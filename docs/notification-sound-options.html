消息通知 · 音效与触发策略

编辑器已有评论 Toast 但还没有声音；分享页目前只有“作者回复”会提示，其他访客的新评论没有通知。下面有 12 个可试听的音色和 3 套触发策略，先选方向，再改代码。

现状缺口

不是“没有通知”，而是两边不一致：编辑器有评论 Toast，分享页只对作者回复弹提示。

已有视觉提示

编辑器

访客新评论 → 右上角 Toast + 评审 Tab 未读 + 评论引脚；但没有音效。作者自己的操作不会提示。

缺少通知

分享页

只有作者回复会弹 Toast；其他访客的新评论、作者解决状态都不会通知。移动端评论抽屉关闭时也没有未读入口。

音色候选

S9–S12 是 S2 / S7 的玻璃与风铃同族：更低、更暖、下行收束和单音水晶。点击「试听」即可播放。

S1 / WOOD

木质轻点

short wood tap

一声低中频木块，起音快、尾音短。像在桌面轻敲一下，不刺耳，连续评论也不会烦。

约 100 ms低侵略适合高频评论
你的偏好
S2 / GLASS

玻璃双音

two-note glass

C6 → G6 两音，带一点高频泛音。更友好、更像“收到消息”，适合给客户用的分享页。

约 200 ms清晰比 S1 更显眼
S3 / DIGITAL

数字脉冲

double blip

两声短促的高频脉冲，干净、工具感强。适合内部编辑器，但音量稍大时容易显得尖锐。

约 90 ms极短偏冷 / 偏尖
S4 / PAPER

纸片轻响

soft paper pop

带滤波的短噪声 + 一点点低频，像纸片翻动。最不“电子”，但笔记本扬声器上可能偏轻。

约 80 ms自然小音量下可能听不清
S5 / DEEP

深水低音

low water drop

像一滴水落在低音木板上，低、暖、尾音短。比 S1 更沉一点，适合长时间开着编辑器的场景。

约 200 ms温暖依赖低频扬声器
S6 / RETRO

复古滴答

lo-fi double tick

两声略带电子感的短滴答，像老式终端确认输入。个性强，但和深色工具界面是否协调需要试。

约 110 ms有辨识度可能出戏
S7 / CHIME

三音风铃

three-note chime

C6–E6–G6 三音上行，清晰、友好、有“消息到了”的完成感。比 S2 更长，存在感也更强。

约 360 ms悦耳你已选比双音更抢注意
S8 / THUMP

轻鼓双击

soft double thump

低频轻鼓 + 一点纸面噪声，两声一组。最有“打断感”，适合希望绝对不漏消息的编辑场景。

约 240 ms最明显可能偏重 / 惊扰
S9 / FIFTH

纯五度玻璃

warm glass fifth

C5–G5，比 S2 低一个八度。仍然是玻璃双音，但更暖、更沉，适合编辑器或长时间评审。

约 220 ms温暖S2 同族比 S2 低
S10 / DESCEND

风铃下行

descending chime

G6–E6–C6 三音下行，句尾收束，不催促。和 S7 同一家族，但比上行版本更平静，适合分享页。

约 340 ms平静S7 同族存在感适中
S11 / MARIMBA

木质双音

warm marimba pair

E5–A5 的木质双音，像马林巴。它是 S1 和 S2 之间的桥：有双音提示，但不那么亮、不那么“电子”。

约 180 ms温暖S2 同族不如玻璃清亮
S12 / CRYSTAL

水晶单音

single crystal strike

单音 G6，带高阶泛音，像轻敲水晶。信息量最低、最精致；适合只想听到“有动静”的编辑器。

约 350 ms精致S2/S7 同族不强调旋律

音效为 Web Audio 实时合成，没有外部音频文件；最终实现会使用同一套合成参数，避免额外资源请求。

触发策略

同一套音效，不同的“什么时候响”。推荐先安静，再让用户自己打开更积极的提醒。

N1 / QUIET

安静优先

只在页面不可见、或评论面板关闭时响；连续评论合并为一次。

  • 不打断输入
  • 桌面端更安静
  • 移动端不会连续叮
N2 / IMMEDIATE

即时提醒

每条新评论 / 回复都响，1.5 秒内合并；评论面板打开时也响。

  • 最不容易漏消息
  • 高频评论时会吵
  • 需要更明显的静音入口
N3 / KEY ONLY

只看关键事件

只对作者回复 / 解决状态响；普通访客评论只更新未读和 Toast。

  • 适合客户链接
  • 会漏掉其他访客评论
  • 编辑器需要单独配置

分享页通知补齐

分享页需要和编辑器一样有“消息到达”的视觉反馈，不只是音效。

通知规则

  • 其他访客新评论 / 回复：Toast + 评论 dock 未读 + 引脚
  • 作者回复 / 解决：Toast 标明“作者”，解决不响音效
  • 自己的评论不回显通知（按 user_id 过滤）
  • 面板打开时只插入卡片 + “新”标记，不弹全屏提示
  • 移动端抽屉关闭时，评论 FAB 显示未读数
