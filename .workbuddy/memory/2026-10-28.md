# 2026-10-28

## 场馆白膜建模项目（G:/WorkSpace/demo）

**需求**：Vue3 + TS + Vite + 3D，基础白膜（仅体块）场馆建模与查看：网格（1 米）上点选画面积图 → 输入高度 → 生成场馆白膜 → 馆内继续画展台（同样面积图 + 高度）。

**技术选型**
- Three.js r186（`three/examples/jsm/controls/OrbitControls.js`），Vite 7 + Vue 3.5 + vue-tsc 3
- 无 UI 框架，纯手写 CSS 设计系统（`src/styles.css`，浅色纸感 + 蓝色绘制强调色 #2f5fe0）

**核心实现**
- `src/core/polygon.ts`：鞋带面积、质心、点内判定、多边形等距内缩 `insetPolygon`（求相邻偏移线交点）、自相交检测、重叠/包含检测、网格吸附
- `src/core/build.ts`：`buildMassing(points, {height, thickness})` = 楼板（ShapeGeometry）+ 有厚度墙圈（ExtrudeGeometry，外轮廓 + 内缩轮廓作 hole），rotateX(-90°) 时 shape.y 取 -z 以免镜像；顶面敞开便于看内部
- `src/core/Stage.ts`：场景/光照（半球光 + 低角度主光投影 + 补光）/自定义 1m+10m 网格/地面/射线拾取（Plane 数学求交 + 1m 吸附）/草稿预览（线 + 半透明面 + 顶点 + 虚线闭合边 + 橡皮筋）/高度预览（半透明蓝体量）/BoxHelper 选中框/相机缓动与视角适配
- `src/App.vue`：状态机模式 `idle | draw-venue | height-venue | draw-booth | height-booth`，Vue 状态 → Stage 单向同步（watch）；快捷键盘 Enter 闭合/确认、Esc 退出、Ctrl+Z 撤销、Backspace 撤销、G 网格
- `src/components/Inspector.vue`：场馆/展台列表、面积/周长/覆盖率、高度滑杆（实时重建）、删除
- `src/components/ActionDock.vue`：底部绘制条（顶点数/面积/撤销/闭合）+ 高度确认条（滑杆 + 数字输入 + 预设 chip）

**交互约定**
- 绘制场馆/展台时自动切俯视；闭合轮廓后切 3/4 视角并在拖动高度时实时预览
- 展台必须完全在场馆内缩 0.4m 范围内，且不可与已有展台重叠（顶点 + 边中点采样 + 线段相交判定）
- 重绘场馆时仍在范围内的展台保留，超出的自动移除并提示
- **绘制展台时场馆自动半透明**（`Stage.setVenueXray`，由 `syncMode` 按模式驱动）：墙体 opacity 0.42 / 双面 / depthWrite off / 不投影，隐藏楼板让地面网格在馆内可见，另加地面轮廓线 `footprint` 标定范围；退出展台流程自动恢复实心与楼板
- **网格随模式显隐**：`gridWanted = mode !== 'idle' || !venue`，绘制/定高时显示、浏览已有场馆时隐藏（图例随网格一起隐藏），视图工具条「网格」按钮仍可手动覆盖
- 确认展台后用 `fit(points, height, 2.6)`（约 61° 俯角）回看，避免展台被 8m 外墙挡住

**验证**：Playwright（playwright-core + 本地 chromium-1217，SwiftShader）跑全流程 13 项断言全通过；dev 与 prod 构建均无控制台报错。注意：该无头软件渲染环境部分情况下阴影很弱，实机 GPU 正常。

**待办/可扩展**：展台命名、导出 glTF/JSON、尺寸标注、多选与拖拽移动、撤销栈。

## 追加：展台形态与编辑能力（同日）

**展台白膜形态**（`buildBooth` in `src/core/build.ts`）
- 顶部闭合：厚度 0.12m 的顶板（`BOOTH_TOP`），在 height-0.12 ~ height
- 侧边只保留地面到 1m 的实心裙墙/台座（`BOOTH_SKIRT = 1`），中间通透
- 其余墙面全部去除；高度 < 1m 时裙墙自动压缩，整体成为实心块
- 场馆（`buildMassing`）仍是开口白膜，不变

**编辑能力**
- 拖动：浏览模式下按住展台直接拖动（先自动选中），位移吸附 1m；越界/重叠则回弹并 toast。实现：`Stage.onPointerDown` 建 DragState、`updateDrag` 移动 group.position、抬手后回调 `onMoveBooth` 由 App 烘焙点集
- 旋转：`Alt+拖动` 自由旋转（绕多边形面心，group.rotation.y = -delta，位置补偿 T = C - R·C），抬手回调 `onRotateBooth`；面板另有 ↺/↻ 90° 按钮
- 合并：`Ctrl/⌘ 点选`多选（面板行或画布）→ 「合并展台」，用 `polygon-clipping` 的 `union` 做布尔并集，结果必须是单一多边形，高度取最大值
- 重叠判定从"边相交"改为 **相交面积 > 0.02 m²**（`polygon-clipping.intersection`），否则贴边拼接会被误判为重叠
- Delete 删除选中展台；选中状态由 `selectedId` 改为 `selectedIds: string[]`（Stage 用 Map<id, BoxHelper> 支持多个选中框）

## 追加：角柱 + 合并语义调整（同日）

- **角柱**：`buildBooth` 在每个真实转角（`corners()` 跳过共线点）放 0.16m 方柱，从台座顶面顶到顶板底，沿进入边方向旋转对齐
- **合并语义改为「只合并模型，不合并数据」**：`Booth.groupId` 标记合并组；
  - 组内高度一致 → `unionOutline()` 用 polygon-clipping 求并集，渲染成**一个** mesh（内部接缝消失）
  - 高度不一致 → 各自渲染，但共用一个描边色
  - 右侧列表始终保留独立条目，用同色小方块 `.gdot` 标记；组色由 `groupColor(gid)` 从 8 色调色板取
- **高度不一致时弹窗**：`mergeDialog` 提示「统一为「展台 XX」的 X.XXm」或「保留各自高度」；统一取当前选中展台（activeBoothId）的高度
- 支持**取消合并**（列表合并栏按钮，清空 groupId）；删除成员后若组内只剩 1 个自动解散
- 合并组成员拖动/旋转会**整组一起变换**（Stage `dragIds/dragTargets/dragCenter`，App `groupIdsOf`，绕合并组包围盒中心）
- 选中框由 BoxHelper 改为 **Box3Helper + depthTest:false**（合并组内没有独立 mesh，且选中时不被外墙遮挡）；拖动期间隐藏对应选框
- 踩坑：`refreshPickables` 忘了把 `groupMeshes` 放进拾取列表，导致合并后的整体无法点选/拖动——已修

## 追加：小展台闭合 bug + 展台命名 + 3D 名称标注

- **Bug**：绘制时"点击起点闭合"阈值原为 1.2m，1×1 展台第 4 个点距起点正好 1m 会被提前闭合 → 变成三角形。改为 **< 0.5m**（必须几乎点在起点上），双击/Enter/按钮闭合不受影响
- **重命名**：右侧列表点击名称文字（`.meta .name`）就地变输入框，Enter/失焦提交、Esc 取消，`emit('rename', id, name)` → `renameBooth`
- **3D 名称**：`CSS2DRenderer` 叠加层（pointer-events:none, z-index:1），每个展台在其面心上方 height+1.62 处挂 `CSS2DObject`（白底气泡 `.booth-label`）+ 一条 depthTest:false 的竖直引线（height+0.02 → +1.5）；标签挂在展台 group 上，拖动/旋转自动跟随
- 视图工具条新增「名称」开关（默认开），`Stage.setLabelsVisible()` 切换标签与引线；`setBooths` 里先 `clearLabels()`（移除 DOM 节点并释放线材质）再重建，避免残留

## 追加：Alt 旋转 90° 吸附

- `Stage.updateDrag` 旋转分支对 `rot`（three 的 +Y 旋转，弧度）做四分之一圆吸附：`nearest = round(rot / (π/2)) * (π/2)`，差值 < 7° 时取 `nearest`；随后 `d.angle = -rot` 保证提交时角度一致
- 新增 `onRotateDrag(deg|null)` 回调：拖动中回传角度、抬手回传 null；App 用 `rotateDeg` 驱动左上角 HUD（复用 `.coord` 样式），吸附态加 `.snap` 高亮
